# JARS — Personal Financial Reporting

JARS is a self-hosted, single-user application built and operated by one
individual to aggregate and report on their own personal financial accounts. It
is not a commercial product and has no third-party or external users.

## Privacy Notice

**Data handling.** Account data retrieved via Plaid is stored only in a local
database on hardware the operator controls. Access tokens are encrypted at rest;
all communication with Plaid uses TLS 1.2+. Data is never sold, shared with, or
transmitted to any third party. The operator can delete any stored data at will,
and disconnecting an institution removes its stored credentials.

**Scope.** JARS is used solely by its author for personal financial tracking,
budgeting, and performance reporting across their own accounts.
